# 05 — خطة الاختبار (TEST PLAN)

> مصفوفة حالات الاختبار. لا يُكتب «تم الاختبار» دون تشغيل موثّق. إذا تعذّر التشغيل يُكتب **`NOT RUN`** وسببه. الحالة الحالية: لم تُبنَ أي وحدة بعد → كل الحالات `NOT RUN (module not built)`.

## لكل وحدة نغطّي
- اختبارات نموذج البيانات والتحقق من الحقول.
- اختبارات انتقالات الحالة (status transitions).
- اختبارات صلاحيات سالبة: مستخدم غير مصرّح لا يقرأ/يعدّل/يصدّر/يحمّل المرفقات.
- اختبارات التاريخ وحالات البيانات الناقصة والصفر.
- اختبارات إنشاء/تعديل/أرشفة/إغلاق.
- اختبار تثبيت التطبيق من مستودع نظيف دون إعدادات مخفية.
- Smoke test بعد `bench migrate`.

## صيغة الحالة
`ID | الهدف | المدخل | النتيجة المتوقعة | النتيجة الفعلية | Pass/Fail`
