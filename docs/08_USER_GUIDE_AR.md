# 08 — دليل المستخدم (عربي)

> يُبنى تدريجياً مع كل وحدة (شرط بوابة لكل Gate). الحالة: لا توجد وظائف مبنية بعد.

## مقدمة
نظام متابعة القرارات والمبادرات والتقارير للجمعية. واجهة عربية، تُستخدم من المتصفح على سطح المكتب والجوال للمتابعة الأساسية.

## الوحدة 1 — القرارات واللجان *(يُكتب بعد بناء Sprint 1)*
- كيف أنشئ لجنة؟
- كيف أسجّل اجتماعاً وأرفق محضره؟
- كيف أضيف قراراً وأحدّد له مسؤولاً وتاريخ استحقاق؟
- كيف أحدّث حالة القرار وأضيف ملاحظة متابعة؟
- كيف أقرأ تقرير القرارات المتأخرة؟
