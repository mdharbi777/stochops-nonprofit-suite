# 08 — دليل المستخدم (عربي)

> يُبنى تدريجياً مع كل وحدة (شرط بوابة لكل Gate). الحالة: لا توجد وظائف مبنية بعد.

## مقدمة
نظام متابعة القرارات والمبادرات والتقارير للجمعية. واجهة عربية، تُستخدم من المتصفح على سطح المكتب والجوال للمتابعة الأساسية.

## الوحدة 1 — القرارات واللجان ✅ (مبنية — Sprint 1)

الدخول من المتصفح: `http://nonprofit.localhost:8000/app` ثم ابحث عن DocType من شريط البحث أو الرابط المباشر.

### 1) إنشاء لجنة
«Committee» ← **+ Add Committee** ← أدخل **اسم اللجنة** (إلزامي وفريد)، **نوع اللجنة** (مجلس إدارة/لجنة/فريق عمل/أخرى)، **المنسّق** (مستخدم)، والحالة (نشطة افتراضياً). احفظ.

### 2) تسجيل اجتماع ومحضره
«Meeting» ← **+ Add Meeting** ← اختر **اللجنة**، **عنوان الاجتماع**، **تاريخ الاجتماع**، وأرفِق **محضر الاجتماع** (اختياري). الحالة تبدأ **Draft**؛ عند تغييرها إلى **Approved** يُسجّل النظام المعتمِد وتاريخ الاعتماد تلقائياً. بعد الاعتماد لا يُعدّل المحتوى إلا بدور إداري.

### 3) إضافة قرار
«Decision» ← **+ Add Decision** ← اختر **الاجتماع** (تُجلب اللجنة تلقائياً)، **عنوان القرار**، **المسؤول**، **تاريخ الاستحقاق**، والأولوية. رقم القرار (DEC-YYYY-#####) يُولّد تلقائياً.

### 4) تحديث الحالة والمتابعة
غيّر **الحالة** (Open → In Progress → Completed/Cancelled). كل تغيّر حالة يُسجَّل تلقائياً في **سجل المتابعات**. لإغلاق القرار (Completed) يلزم **ملاحظة الإكمال**، ويُملأ تاريخ الإكمال تلقائياً. **التأخير** يظهر تلقائياً عند تجاوز تاريخ الاستحقاق دون إكمال (لا يُدخل يدوياً).

### 5) التقارير
- **Overdue Decisions** (القرارات المتأخرة): `/app/query-report/Overdue Decisions` — فلاتر اللجنة/المسؤول، وعمود أيام التأخير.
- **Decisions by Committee**: متابعة القرارات حسب اللجنة/المسؤول/الحالة.
- التصدير CSV من زر Actions وفق صلاحياتك.

### بيانات تجريبية
لتعبئة عيّنة آمنة: `bench --site nonprofit.localhost execute stochops_nonprofit.setup.seed_demo.run` — وللحذف: `...seed_demo.clear`.
