# BACKLOG — أفكار مؤجّلة خارج نطاق MVP

> أي فكرة أو طلب خارج الوحدات الثلاث يُسجَّل هنا **دون تنفيذ**، ولا يُخلط بالإصدار الأول.

## خارج النطاق صراحةً (مرفوض في MVP — يُعاد تقييمه لاحقاً فقط بقرار المالك)
- بوابة مستفيدين / تسجيل مستفيدين.
- منصة أو بوابة تبرعات.
- نظام رواتب.
- محاسبة عامة / دفتر حسابات / معاملات مالية.
- CRM.
- نظام مشتريات / عقود / موردين / فواتير.
- موقع تسويقي منفصل.
- تكاملات حكومية أو بنكية.
- إشعارات SMS / WhatsApp / SMTP مدفوع.
- محرك استيراد مخصّص (نكتفي باستيراد CSV القياسي من Frappe).
- multi-tenant داخل قاعدة واحدة / `Charity` DocType متعدد العملاء.
- إدارة اشتراكات/فواتير العملاء وتسعير تجاري.

## أفكار AI المؤجّلة (Sprint 6 — بموافقة وتكلفة محددة)

- صياغة مسودة تقرير شهري من بيانات مؤكدة.
