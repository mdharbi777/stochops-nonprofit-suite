- **الواجهة المبرندة:** `/nos/expenses` (طلبات + إنشاء + تغيير حالة بملاحظة بتّ) + بطاقة اللوحة + حقل حدّ الاعتماد في صفحة الإعدادات + seed وهمي.
- **الاختبارات:** إجمالي **68/68** (7 جديدة: العزل، فصل الواجبات، اعتماد مدير آخر ضمن الحد، تجاوز الحد، ملاحظة إلزامية، المنسّق لا يعتمد، غير السالب + القراءة فقط). verify_install يشمل النوع.
- **GATE N4: PASS** (بيانات وهمية) — لا دفع بنكي ولا محاسبة مزدوجة؛ DPA/PDPL قبل أي بيانات مالية فعلية.

### N5 — التقارير المحكومة والالتزامات الحكومية (منصة الفاضل) — 2026-10-19
- **DocType:** `Compliance Obligation` (التزام حوكمة/تنظيمي) — نوع/جهة مشرفة/مسؤول/استحقاق/تذكير قبل أيام/حالة/مرفق. التأخير **صفة مشتقّة** (`is_overdue`، غير مخزّنة)؛ `completed_on` خادمي عند «مكتمل» ويُمسح عند التراجع.
- **تذكيرات داخل النظام (Scheduler):** إشعاران (قبل الموعد بـ7 أيام + عند التأخّر) للمسؤول عبر Notification الجاهز — **لا SMS/بريد مدفوع ولا تكامل حكومي مباشر**. (إجمالي الإشعارات صار 8.)
- **تقرير محكوم:** `Compliance Obligations` (Script Report، يحترم الصلاحيات والعزل) — أيام متبقية/متأخر، مُضاف كتبويب في صفحة التقارير المبرندة `/nos/reports`.
- **العزل:** Compliance Obligation مربوط بخطّافات تعدّد الجمعيات.
- **الواجهة المبرندة:** `/nos/compliance` (قائمة + إنشاء + تغيير حالة، تمييز المتأخر) + بطاقة اللوحة + seed وهمي + verify_install (النوع + التقرير).
- **الاختبارات:** إجمالي **73/73** (5 جديدة: العزل، الإكمال الخادمي والتراجع، التأخير المشتق بلا حقل مخزّن، تشغيل التقرير مُعزَّلاً، القراءة فقط). `after_migrate` يُعيد تشغيل الإعداد الـidempotent فتُنشأ الإشعارات الجديدة على الترقية.
- **GATE N5: PASS** — قوالب وتذكيرات داخل النظام فقط؛ أي تكامل حكومي/بنكي مباشر مؤجّل إلى تصريح واعتماد مستقل (حدّ ثابت في نطاق v2.0).

### N6 — الموظفون والمتطوعون والعقود والمشتريات (منصة الفاضل) — 2026-10-19

- **الاختبارات:** إجمالي **79/79** (6 جديدة: عزل المنسوبين وغياب حقول الرواتب، كشف الهوية إدارياً، تواريخ العقد، فصل واجبات المشتريات والاعتماد ضمن الحد، تجاوز الحد والمنسّق لا يعتمد، القراءة فقط).

### P1 — Privacy Core + بوابة الإنتاج (منصة الفاضل / PDPL) — 2026-10-19
- **طبقة `privacy_core` مشتركة** (وثيقة PDPL §0/§13) بـ5 أنواع: `Privacy Configuration` (Single — **بوابة إنتاج البيانات الحقيقية مغلقة افتراضياً**؛ فتحها يتطلّب مسؤول خصوصية + إصدار سياسة ويُختم خادمياً؛ أعلام بيانات حقيقية؛ علم AI خارجي)، `Regulatory Rule` (مرجعية بمصدر/إصدار/مراجعة، افتراضي `LEGAL_REVIEW_REQUIRED`)، `Data Field Catalog` (تصنيف الحقول)، `Processing Activity Record` (RoPA، معزول بالجمعية)، `Sensitive Access Log` (سجل اطّلاع/كشف/تصدير — بيانات وصفية فقط، معزول).
- **بوابة الإنتاج (`production_privacy_gate`):** `privacy_core.assert_gate_open()` تمنع أي عملية ببيانات حقيقية حتى فتح البوابة؛ لا يمكن تمكين بيانات حقيقية والبوابة مغلقة. اجتياز الكود ≠ امتثال قانوني.
- **تسجيل كشف الهوية:** `beneficiaries.reveal_national_id` و`personnel.reveal_national_id` تسجّلان حدث `reveal` في `Sensitive Access Log` (بلا تخزين القيمة).
- **تهيئة idempotent** (`ensure_privacy_core`) عبر after_install/after_migrate: تزرع المرجعية التنظيمية (6 قواعد بحالة مراجعة قانونية) وكتالوج الحقول الشخصية/الحسّاسة.
- **العزل:** Processing Activity Record + Sensitive Access Log مربوطان بخطّافات تعدّد الجمعيات؛ المرجعية والكتالوج والإعدادات لمشغّل المنصّة فقط.
- **الواجهة المبرندة:** `/nos/privacy` (حالة البوابة + الإعداد + سجل الاطّلاع + RoPA) + بطاقة اللوحة.
- **غير هادم:** migrations سينكرونية فقط؛ لم تُمسّ وحدات N1–N7؛ الاختبارات **91/91** (6 جديدة: البوابة مغلقة افتراضياً، فتحها يتطلّب المتطلبات، عزل السجل الحسّاس + تسجيل الكشف، عزل RoPA، تقييد المرجعية بالمنصّة، زرع الكتالوج/القواعد).
- **GATE P1: PASS.** التالي P2 (الحسابات بدعوات)، ولا إنتاج ببيانات حقيقية قبل اعتمادات القسم 17 وفتح البوابة يدوياً.

### P2 — الحسابات بدعوات بريدية (منصة الفاضل / PDPL §8) — 2026-10-19
- **إضافة الحسابات صارت بدعوة** (المسار المفضّل `accounts.invite_account`): يُنشأ الحساب **معطّلاً بلا كلمة مرور**، ويُرسَل رابط أحادي قصير العمر (3 أيام) من `ops@stochops.com` ليضبط المدعو كلمة مروره بنفسه عبر `/nos/accept-invite` — **لا تُرسَل كلمة مرور في البريد**.
- `accounts.accept_invite` (guest + rate_limit 10/س): يتحقّق من الرمز الموقّع ويفعّل الحساب بكلمة مرور المستخدم.
- `accounts.request_password_reset` (guest + rate_limit 5/س): استعادة عبر رابط Frappe الآمن **دون إفشاء وجود الحساب** (رسالة عامة).
- **توافق للخلف:** `create_account(..., password=None)` — مع كلمة مرور يُبقي المسار المباشر (للاختبارات/seed)، وبدونها يحوّل تلقائياً إلى الدعوة. لم تُكسر أي اختبارات قائمة.
- **تدقيق:** إنشاء الحساب وتفعيله/تعطيله يُسجَّل كـ`permission_change` في `Sensitive Access Log` (ربط P1).
- **الواجهة:** `/nos/accounts` تُرسل دعوة (بلا حقل كلمة مرور) + صفحة `/nos/accept-invite` المبرندة.
- **غير هادم؛** الاختبارات **95/95** (4 جديدة: الدعوة تُنشئ معطّلاً ثم التفعيل، رمز غير صالح يُرفض، غير المدير لا يدعو، الاستعادة لا تُفشي).
- **GATE P2: PASS.** التالي P3 (خصوصية المستفيدين/المتبرعين: الأساس/الموافقة/ACL الحالة/الحقوق/DPIA).

### P3 — خصوصية المستفيدين والمتبرعين (منصة الفاضل / PDPL §4-6) — 2026-10-19
- **DocTypes (3):** `Consent Record` (موافقة بالغرض/الأساس/نسخة الإشعار/الطريقة، قابلة للسحب مع ختم withdrawn_on)؛ `Privacy Rights Request` (حق صاحب البيانات — **مهلة 30 يوماً** مشتقّة من الاستلام + تمديد 30 بمبرر + تأخير مشتق + ختم الإنجاز)؛ `Privacy Impact Assessment` (DPIA — الاعتماد يتطلّب جهة اعتماد بشرية، لا يصدر من الأداة). الثلاثة معزولة بالجمعية.
- **ACL على مستوى الحالة (PDPL §7):** حقل `case_worker` على `Beneficiary` و`Assistance Request` يُضبط تلقائياً لمنشئ السجل من المنسّقين؛ **المنسّق يرى حالاته المُسندة فقط**، والمدير/المطّلع/بريك-جلاس يرون كل حالات الجمعية — مفروض على الاستعلام (`_case_condition`) والسجل (`has_case_permission`). غير هادم: سلوك المدير/المطّلع كما كان.
- **تذكير داخل النظام** لطلب الحق قبل الاستحقاق بـ5 أيام للمسؤول (الإشعارات صارت 10).
- **الواجهة المبرندة:** `/nos/rights` (طلبات الحقوق + الموافقات + تقييمات الأثر) + بطاقة اللوحة؛ seed وهمي (مسودة DPIA + طلب حق + موافقة).
- **الاختبارات:** إجمالي **100/100** (5 جديدة: مهلة الحقوق والتمديد، عزل الطلبات، سحب الموافقة، اعتماد DPIA بشري، ACL الحالة — المنسّق يرى حالته فقط والمدير يرى الكل). verify_install يشمل الأنواع الثلاثة.
- **GATE P3: PASS** (بيانات مصطنعة؛ DPIA معتمد + فتح البوابة قبل أي بيانات مستفيدين حقيقية). التالي P4 (الإفصاح والتقارير المحوكمة).
