# P0 — كتالوج سير العمل (Workflow Catalog)

> وفق §5 من مواصفات V2. الحالة الراهنة: منطق الحالات في **Controllers** (لا محرك Frappe Workflow). المستهدف: محرك انتقالات قابل للضبط ضمن حدود محمية.

## 1. الحالات القياسية (لكل نوع طلب)
مسودة · مقدّم · قيد المراجعة · يحتاج استكمالاً · معتمد · مرفوض · قيد التنفيذ · مكتمل · ملغى.
> يُسمح لكل نوع بالحالات المناسبة له فقط.

## 2. ضوابط كل انتقال (إلزامية)
الدور المخوّل · الشروط · الحقول الإلزامية · المبلغ/درجة الحساسية · **منع الموافقة الذاتية عند تعارض المصالح** · سبب الرفض/الإرجاع · (تاريخ/وقت/اسم الفاعل) · إخطار الأطراف · **لا تعديل صامت على سجل معتمد** · idempotency · توقيت السعودية وأيام العمل.

## 3. التدفقات الأساسية

### 3.1 طلب المساعدة
`مسودة → مقدّم → قيد المراجعة → (يحتاج استكمالاً ⟲ | مرفوض | معتمد) → قيد التنفيذ → مكتمل`
- تقييم أهلية قبل الاعتماد · الاعتماد حسب الدور/الحدّ · توثيق الصرف/التسليم + إثبات قبل الإغلاق.
- **الحالي:** إنشاء/عرض فقط ⇒ **فجوة P3**.

### 3.2 طلب المصروف
`مسودة → مقدّم → اعتماد(requester≠approver، ≤حدّ المعتمِد) → (مرفوض | معتمد) → أمر صرف → مصروف → مطابقة`
- **الحالي:** فصل الصلاحيات + حدّ الاعتماد + ملاحظة قرار + ختم خادمي + track_changes. ✅ (الأساس موجود) · أوامر الصرف/المطابقة ⇒ فجوة.

### 3.3 المشتريات
`طلب → عروض الموردين → مقارنة → اعتماد(حدّ) → أمر شراء → استلام → مصروف مرتبط (بلا ازدواج)`
- **الحالي:** CRUD فقط ⇒ **فجوة P3**.

### 3.4 قرار اللجنة
`اجتماع → محضر → قرار → مسؤول + موعد → (تنبيه تأخير/تصعيد) → إثبات → إقفال/تصعيد`
- **الحالي:** منع الإكمال دون ملاحظة · تاريخ إكمال خادمي · تسجيل متابعة تلقائي · تأخير مشتق · اعتماد الاجتماع خادمي · قفل المحضر المعتمد. ✅ (أقوى تدفق حالياً).

### 3.5 طلب موظف/إداري
`طلب → صاحب الصلاحية → اعتماد → تنفيذ → أثر في السجل` — **الحالي:** ناقص ⇒ فجوة.

## 4. محرك سير العمل المستهدف (P3)
- تعريف أنواع الطلبات وحالاتها وانتقالاتها كبيانات قابلة للضبط لكل جمعية **ضمن allowlist سياسات محمية**.
- SLA قابل للضبط + تصعيد + توقيت السعودية.
- سجل غير قابل للعبث من صلاحيات التطبيق العادية؛ أي تصحيح عبر مراجعة/نسخة تعديل.
- الإشعار دليل مساعد لا مرجع؛ **قاعدة البيانات + سجل الأحداث** هما المرجع.

## 5. الفجوة والقرار
الأساس موجود للقرارات والمصروفات (controller). المستهدف: **محرك موحّد** يغطّي كل الأنواع مع ضوابط §5 ⇒ **يُصمَّم مبكراً (P0) ويُبنى في P3** لتفادي إعادة هندسة الصفحات.
