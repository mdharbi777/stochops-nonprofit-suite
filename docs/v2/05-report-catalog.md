# P0 — كتالوج التقارير والتصدير (Report Catalog)

> وفق §8 من مواصفات V2. **تصدير Excel/PDF متطلب أساسي في V2** مع ضوابط صلاحيات/مستأجر/إخفاء حقول حساسة على الاستعلام الأصلي وعلى مهمة التصدير وعند التنزيل.

## 1. الحالة الراهنة (مُتحقَّقة)
- **6 Script Reports** في Frappe: `Beneficiary Categories`(مُجهّل+إخفاء خلايا صغيرة)، `Compliance Obligations`، `Decisions by Committee`، `Executive Summary`، `Initiatives Overview`، `Overdue Decisions`.
- تستخدم `frappe.get_list` ⇒ تحترم الصلاحيات. تُعرض في `/nos/reports`.
- **تصدير Excel/PDF في واجهة /nos: غير موجود.** (Frappe Desk يتيح تصديراً عاماً، لكن ليس في الواجهة المحوكمة ولا بضوابط §8.) ⇒ **فجوة أساسية P4**.

## 2. قواعد التصدير المستهدفة (§8.1)
- زرّا **Excel** و**PDF** نصيّان في قوائم/تقارير الوحدات حسب الصلاحية.
- خيار واضح: **النتائج المفلترة** مقابل **كل النتائج المصرّح بها** + إظهار عدد الصفوف/النطاق/المعايير/الأعمدة قبل التصدير.
- الصلاحيات + عزل المستأجر + إخفاء الحقول الحساسة على الاستعلام **وعلى مهمة التصدير الخلفية** + إعادة تحقق عند التنزيل.
- **سجل تصدير:** المستخدم/الجمعية/التقرير/الفلاتر/العدد/الوقت/الحالة/الوجهة؛ روابط مؤقتة محمية + إزالة تلقائية.
- مهام كبيرة **غير متزامنة** مع تقدّم وتعامل آمن مع الفشل.

### Excel (§8.2): ورقة `Data` (عناوين ثابتة/أنواع صحيحة/تجميد/تصفية/RTL) + `Report Info` + `Summary` (مطابق للوحة) + **حماية حقن الصيغ** + توافق Excel العربي.
### PDF (§8.3): A4، خط عربي مضمّن مرخّص، ترويسة الجمعية/التقرير/المعايير، RTL صحيح بلا قصّ، فصل الملخّص، **علامة سرية** عند حساسية، إخفاء غير المخوّل.

## 3. كتالوج التقارير المستهدف (§8.4)
| التقرير | مصدر البيانات | المرشحات | المخرجات | الحالة |
|---|---|---|---|---|
| سجل المستفيدين | Beneficiary | الحالة/البرنامج/الفترة | العدد/التوزيع/الحالات | **جاهز جزئياً** (تقرير مُجهّل موجود) · تصدير ناقص |
| الطلبات والمساعدات | Assistance Request | النوع/الفترة/الحالة | الطلبات/القيم/زمن المعالجة | **ناقص** |
| الأهلية والقرارات | (أهلية — غير موجودة) | البرنامج/القرار/المقيم | نتائج/قرارات/أسباب | **ناقص** (يتطلب نموذج أهلية) |
| المتبرعون والمنح | Donor/Grant | المانح/المنحة/الفترة | الالتزامات/التخصيصات/المتبقي | **ناقص** |
| المصروفات التشغيلية | Expense Request | البرنامج/البند/الفترة | المعتمد/المصروف/المتبقي | **ناقص** |
| المشتريات | Procurement Request | المورد/الحالة/الفترة | الطلبات/الأوامر/الاعتماد | **ناقص** |
| الموارد البشرية | Personnel/Contract | النوع/الحالة/القسم | إجمالي السجلات/التكليفات (بلا بيانات شخصية زائدة) | **ناقص** |
| قرارات اللجان | Decision | اللجنة/الحالة/الموعد | مفتوحة/متأخرة/مغلقة | **جاهز** (`Decisions by Committee`+`Overdue Decisions`) · تصدير ناقص |
| المهام والموافقات | Initiative Task/Decision | الدور/المسؤول/الفترة | التراكم/التأخير/الإنجاز | **ناقص** |
| الامتثال والخصوصية | Compliance/Rights/Incident | النوع/الحالة/الفترة | طلبات/حوادث/مؤشرات مجملة (صلاحية مرتفعة) | **جاهز جزئياً** (`Compliance Obligations`) · تصدير ناقص |
| سجل التدقيق والتصدير | Sensitive Access Log + سجل تصدير(جديد) | الفاعل/الإجراء/الفترة | الأنشطة المقيّدة/الأثر | **ناقص** (سجل التصدير جديد) |

> **قاعدة:** لا يُنشأ تقرير إلا بتوفّر حقوله ومصادره. غير الجاهز = gap صريح، **بلا نتائج وهمية**.

## 4. معيار قبول P4
تطابق العدد/الإجماليات بعد المرشحات مع اللوحة لنفس تاريخ القطع · دقة العربية في Excel/PDF · **لا تسرّب حساس أو cross-tenant** في المخرجات · سجل تصدير فعّال.
