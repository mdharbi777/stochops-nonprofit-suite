# 04 — الأدوار والصلاحيات (ROLES & PERMISSIONS)

> نستخدم نظام أدوار Frappe القياسي ثم User Permissions لتقييد السجلات. **لا نبني نظام تفويض مخصّصاً موازياً لـ Frappe.**

## 1. الأدوار الأربعة
| الدور | النطاق |
|---|---|
| **Nonprofit Admin** | إعداد التطبيق، إدارة السجلات ومستخدمين محدودين، الاطلاع على كل بيانات الجمعية |
| **Executive Viewer** | قراءة التقارير والمؤشرات والقرارات والمبادرات المسموح بها، **دون تعديل** |
| **Committee Coordinator** | إنشاء الاجتماعات والقرارات وتعديل سجلات اللجان المخوّل بها وإسناد المهام |
| **Program Coordinator** | إنشاء البرامج والمبادرات وتحديث المهام والمخرجات والميزانيات الإدارية المخوّل بها |

## 2. مصفوفة الصلاحيات (الوحدة 1 — مبدئية)
| DocType | Nonprofit Admin | Executive Viewer | Committee Coordinator | Program Coordinator |
|---|---|---|---|---|
| Committee | إنشاء/قراءة/تعديل/أرشفة | قراءة (مسموح) | قراءة/تعديل (المخوّل) | — |
| Meeting | كامل + اعتماد | قراءة (مسموح) | إنشاء/قراءة/تعديل (المخوّل) | — |
| Decision | كامل | قراءة (مسموح) | إنشاء/قراءة/تعديل (المخوّل) | — |
| Decision Follow-up | كامل | قراءة | إنشاء/قراءة (المخوّل) | — |
| التقارير | كامل | قراءة (المسموح) | قراءة (المخوّل) | قراءة (المخوّل) |

> سجلات الوحدة 2 (Initiative / Initiative Task) تُضاف للمصفوفة في Sprint 2 (Program Coordinator = إنشاء/تعديل المخوّل؛ Executive Viewer = قراءة).

## 3. مبادئ التطبيق (إلزامية)
- **التقييد خادمي**: role permissions ثم user permissions لتقييد سجلات لجنة/برنامج محدّد. لا يكفي إخفاء الأزرار في الواجهة.
- **اختبر القيد على كل المسارات**: UI، API، التصدير (CSV)، المرفقات، التقارير، والروابط المباشرة — بنفس القيود.
- لا يُستخدم حساب `Administrator` في العمل اليومي.
- تسجيل كل تغيير مهم (الحالة، المسؤول، المبلغ، تاريخ الاستحقاق) مع المستخدم والتاريخ (Frappe audit/version أو Follow-up child table).
- حسابات فردية؛ لا حسابات مشتركة.

## 4. اختبارات الصلاحيات السالبة (أمثلة — راجع 05_TEST_PLAN)
- منسق لجنة (أ) لا يرى محتوى لجنة (ب) المحظورة عليه عبر UI **و**API **و**export.
- Executive Viewer يقرأ ولا يعدّل.
- مرفق خاص (minutes_attachment / evidence) لا يُجلب دون تفويض.
