# تقييمات أثر حماية البيانات (DPIA) — مسودات منفصلة

> **`DRAFT — NOT APPROVED`** (ينطبق على كل تقييم أدناه)
> مسوّدات تقنية تُسهّل العمل، **غير معتمدة**. قبول الخطر قرار بشري من المخوّل لدى الجمعية مع مراجعة قانونية — **لا يصدر من الأداة ولا يُعتمد تلقائياً**. تُسجَّل النسخة المعتمدة لاحقاً في DocType `Privacy Impact Assessment` (الحالة «معتمد» تتطلّب جهة اعتماد). المرجع: PDPL §25 من اللائحة، و[11_PDPL_DESIGN](../11_PDPL_DESIGN.md).
> **الوضع:** SYNTHETIC_DATA_ONLY · لا تشغيل فعلي قبل اعتماد هذه التقييمات + DPA + فتح بوابة الإنتاج.

**هيكل كل تقييم:** الوصف/التدفّق · أصحاب البيانات والفئات والتصنيف · الغرض والأساس · الضرورة والتناسب · المخاطر · تدابير التخفيف (المنفّذ تقنياً) · الخطر المتبقّي · القرار (معلّق) · المراجعة.

---

## 1) DPIA — إدارة المستفيدين  ·  `DRAFT — NOT APPROVED`
- **التدفّق:** تسجيل مستفيد → طلب مساعدة → مراجعة/اعتماد → ربط بمبادرة/صرف (تسجيلي).
- **أصحاب البيانات/الفئات:** مستفيدون وأسرهم؛ الاسم، رقم الهوية (عند المسوّغ)، تواصل، فئة اجتماعية عامة، عدد أفراد الأسرة، طلبات. **تصنيف: حسّاس/حسّاس جداً.**
- **الغرض/الأساس:** دراسة وإدارة طلب المساعدة؛ أساس نظامي (تنفيذ أغراض الجمعية/موافقة حيث تلزم) — يحدّده المختص.
- **الضرورة/التناسب:** أدنى بيانات؛ لا تُطلب صورة الهوية افتراضياً؛ لا سرد تفصيلي في التقارير.
- **المخاطر:** حساسية الحالات؛ إعادة تحديد الهوية؛ اطّلاع غير مخوّل؛ بيانات قُصّر.
- **تدابير التخفيف (مطبّقة):** تشفير/حجب الهوية + كشف إداري مُقيَّد + **سجل اطّلاع** + **ACL على مستوى الحالة** + تقليل البيانات + عزل بالجمعية + تقارير مُجهّلة بإخفاء الخلايا الصغيرة.
- **الخطر المتبقّي:** متوسط (يُخفَّض بالاحتفاظ والتدقيق). **القرار:** معلّق (يعتمده المخوّل). **المراجعة:** [تاريخ].

## 2) DPIA — الموارد البشرية  ·  `DRAFT — NOT APPROVED`
- **التدفّق:** تسجيل موظف/متطوّع → عقد بمدة وتنبيه انتهاء.
- **أصحاب البيانات/الفئات:** موظفون/متطوّعون؛ الاسم، رقم الهوية (مشفّر)، تواصل، مسمّى، عقد. **تصنيف: حسّاس جداً.**
- **الغرض/الأساس:** إدارة شؤون المنسوبين؛ أساس (تنفيذ عقد/التزام نظامي). **لا رواتب فعلية ولا تكامل تأمينات.**
- **الضرورة/التناسب:** بيانات HR أدنى فقط.
- **المخاطر:** تسرّب بيانات منسوبين؛ وصول غير مخوّل.
- **تدابير التخفيف (مطبّقة):** تشفير/حجب الهوية + كشف إداري + عزل بالجمعية + صلاحيات خادمية + تدقيق تغييرات.
- **الخطر المتبقّي:** متوسط. **القرار:** معلّق. **المراجعة:** [تاريخ].

## 3) DPIA — المتبرعون والمنح  ·  `DRAFT — NOT APPROVED`
- **التدفّق:** تسجيل متبرّع/جهة مانحة → تبرّع/منحة (تسجيل قيمة فقط).
- **أصحاب البيانات/الفئات:** متبرعون أفراد/ممثلو جهات؛ الاسم، تواصل، مبالغ. **تصنيف: شخصي/مالي.**
- **الغرض/الأساس:** إدارة التبرعات والمنح وإصدار الإيصالات والتقارير؛ أساس (موافقة/التزام). **لا بوابة دفع.**
- **الضرورة/التناسب:** فصل التواصل التسويقي عن المعاملات؛ لا إضافة تلقائية لقوائم تسويق.
- **المخاطر:** إفصاح غير مبرّر؛ ربط المتبرّع بمستفيدين؛ خلط تسويقي.
- **تدابير التخفيف (مطبّقة):** عزل بالجمعية + **تقارير مانحين مُجهّلة** (لا معرّفات مستفيدين) + `Disclosure Request` deny-by-default + تدقيق.
- **الخطر المتبقّي:** منخفض/متوسط. **القرار:** معلّق. **المراجعة:** [تاريخ].

## 4) DPIA — السجلّات المالية  ·  `DRAFT — NOT APPROVED`
- **التدفّق:** طلب صرف/شراء → مسار اعتماد → تسجيل (لا دفع بنكي).
- **أصحاب البيانات/الفئات:** معتمِدون/مورّدون/مستفيدون من الصرف؛ مبالغ ومرفقات. **تصنيف: مالي/شخصي.**
- **الغرض/الأساس:** حوكمة الصرف والرقابة؛ التزام نظامي/تنفيذ أغراض. **رقم إداري لا قيد محاسبي مزدوج.**
- **الضرورة/التناسب:** حقول الحد الأدنى؛ لا أرقام حسابات بنكية افتراضاً.
- **المخاطر:** تلاعب/تجاوز صلاحية؛ كشف مبالغ شخصية.
- **تدابير التخفيف (مطبّقة):** **فصل الواجبات** + **حدّ اعتماد بالدور + تصعيد** + ملاحظة بتّ + ختم + **تدقيق تغييرات** + عزل.
- **الخطر المتبقّي:** متوسط. **القرار:** معلّق. **المراجعة:** [تاريخ].

## 5) DPIA — الذكاء الاصطناعي والتكاملات الخارجية  ·  `DRAFT — NOT APPROVED`
- **التدفّق:** مهام مسودات (قرارات/تلخيص/تقرير) عبر مزوّد **محلي Mock بلا اتصال**.
- **أصحاب البيانات/الفئات:** لا تُرسل بيانات مستفيدين؛ مؤشرات مُجمّعة/نص ملصق فقط.
- **الغرض/الأساس:** مسودات بمراجعة بشرية؛ **لا قرار آلي** (رفض/صرف/تصنيف خطر).
- **الضرورة/التناسب:** الحد الأدنى؛ المزوّد الخارجي **معطّل افتراضياً** (GATE AI).
- **المخاطر:** تسريب للمزوّد؛ حقن تعليمات؛ استرجاع عابر للمستأجرين.
- **تدابير التخفيف (مطبّقة):** Mock محلي + `ai_external_enabled=false` + **لا تعديل قاعدة بيانات** + النص بيانات لا تعليمات (مقاومة حقن) + تسجيل بلا payload + **منع إرسال بيانات المستفيدين**. أي مزوّد خارجي مستقبلاً يحتاج تقييماً وعقداً وموافقة قبل التفعيل.
- **الخطر المتبقّي:** منخفض (طالما محلي). **القرار:** معلّق لأي تفعيل خارجي. **المراجعة:** [تاريخ].
