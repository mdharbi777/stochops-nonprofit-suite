# الفحص الأمني للتجربة (P6.4)

> على **النسخة التجريبية فقط** وبتصريح. **الفحص الآلي ليس بديلاً عن اختبار اختراق احترافي** للإنتاج الحقيقي.

## 1. فحص آلي — OWASP ZAP (يُشغّله الفريق)
```bash
# على جهاز الفريق، ضد الموقع التجريبي فقط:
docker run --rm -t ghcr.io/zaproxy/zaproxy zap-baseline.py -t https://<staging-host>/nos -r zap_report.html
# أو ZAP Desktop (Automated Scan) على نفس العنوان بعد تسجيل الدخول لتغطية الصفحات المحمية.
```
سجّل النتائج، أصلح الحرج/العالي، أعد الفحص.

## 2. فحص التبعيات والأسرار
```bash
# أسرار في المتتبّع:
git grep -nEI "(password|secret|api[_-]?key|token|BEGIN (RSA|OPENSSH) PRIVATE KEY)" -- . ':!*.md'
git ls-files | grep -E "\.env$|\.key$|\.pem$|/sites/|backup" || echo "no sensitive tracked files"
# تبعيات بايثون (التطبيق بلا تبعيات مخصّصة؛ تُتابَع تبعيات Frappe نفسها):
pip list --outdated 2>/dev/null | head
```

## 3. ضوابط التحكّم بالوصول — مُغطّاة باختبارات آلية (108/108)
| الفحص المطلوب (الوثيقة) | التغطية في الكود |
|---|---|
| عزل بين الجمعيات (UI/API/export) | `TestMultiTenancy` + اختبارات عزل لكل نوع |
| فصل المستخدم الرئيسي والخمسة ذوي الأدوار | مصفوفات الصلاحيات + `has_charity/case_permission` |
| منع الوصول للمرفقات/التقارير/المالية بلا صلاحية (رابط/API) | مرفقات Private + permission_query + has_permission + صلاحيات التقارير |
| تجاوز مسارات الموافقة أو تعديل المالك/الجمعية | فصل الواجبات + حدّ الاعتماد + `set_charity`/`requested_by` خادمية + حارس الجمعية المتقاطعة |
| ACL على مستوى الحالة (مسؤول الحالة فقط) | `_case_condition` + `has_case_permission` |
| كشف رقم الهوية مُقيَّد ومُسجَّل | `reveal_national_id` + Sensitive Access Log |
| بوابة الإنتاج خادمية (لا من الواجهة) | `production_privacy_gate` + `PILOT_SANDBOX` (حظر في الكنترولر) |

## 4. اختبارات يدوية إضافية (تُسجَّل نتائجها)
- محاولة فتح سجل جمعية أخرى عبر `/app/<doctype>/<name>` أو API مباشرة → يُرفض.
- محاولة اعتماد طلب صرف/شراء من مُقدّمه → يُرفض (فصل واجبات).
- محاولة فتح `production_privacy_gate` من الواجهة/الإعداد في PILOT_SANDBOX → يُرفض خادمياً.
- روابط الاستعادة/الدعوة/التأكيد: أحادية وقصيرة العمر.

> وثّق كل نتيجة وتاريخ الإصلاح وإعادة الاختبار. أغلق الحرج/العالي قبل أي انتقال للإنتاج.
