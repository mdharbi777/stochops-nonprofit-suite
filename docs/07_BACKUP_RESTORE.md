# 07 — النسخ الاحتياطي والاستعادة (BACKUP & RESTORE)

## أثناء التطوير
- نسخ محلية تجريبية عند الحاجة فقط.
- **لا تُرفع نسخ قواعد البيانات إلى GitHub** إطلاقاً (مغطّى في `.gitignore`).

## قبل الإنتاج (مؤجّل — سياسة مطلوبة)
- نسخ احتياطي **آلي** لقاعدة البيانات والملفات الخاصة/العامة المشروعة.
- النسخ **مشفّرة** ومخزّنة في مكان مستقل ومصرّح به.
- **تجربة restore حقيقية قبل الإطلاق** — يُسجّل نتيجتها وتاريخها هنا.
- احتفاظ/تدوير، تحقّق من مساحة النسخ، إنذار للفشل، اختبار صلاحيات الوصول.
- لكل جمعية: موقع مستقل + نسخ احتياطي مستقل + إجراء استعادة مستقل.
