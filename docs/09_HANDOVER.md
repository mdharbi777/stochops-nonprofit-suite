# 09 — وثيقة التسليم (HANDOVER)

> تُكمَل عند إنهاء الوحدات الثلاث (Sprint 4). الحالة: Sprint 0.

## محتويات التسليم المطلوبة (مرجع)
1. مستودع خاص منظّم وشفرات Frappe قابلة للتثبيت.
2. تطبيق واحد `stochops_nonprofit` بثلاث وحدات فقط.
3. أوامر/سكربت تجهيز محلي موثّقة ومختبرة.
4. بيانات تجريبية وهمية تُنشأ وتُحذف بأمان.
5. دليل إداري عربي + دليل مستخدم عربي مختصر.
6. جدول الصلاحيات والاختبارات ونتائجها الفعلية.
7. مسودة مستند تسليم لجمعية الإخلاص (دون وعد دعم غير محدود).
8. خطة نقل إلى VPS سعودي (غير منفّذة حتى توفّر الاستضافة).
9. وثيقة تشغيل ونسخ احتياطي واستعادة.
10. Backlog مستقل للأفكار اللاحقة.

## مسودة بيان مجاني للجمعية (نطاق، وليس اتفاقاً موقّعاً)
«تقدّم STOCHOPS للجمعية نسخة تجريبية من نظام متابعة القرارات والمبادرات والتقارير دون رسوم تطوير، ضمن نطاق تجريبي متفق عليه. لا يشمل المشروع أنظمة التبرعات أو المستفيدين أو المحاسبة أو الرواتب أو التكاملات الخارجية. لا يتم إدخال بيانات فعلية أو إطلاق تشغيل إنتاجي إلا بعد الاتفاق على الملكية والصلاحيات والاستضافة وحماية البيانات والمسؤولية عن الدعم والنسخ الاحتياطية.»
